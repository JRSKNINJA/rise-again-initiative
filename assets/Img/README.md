# Rise Again Initiative — Image Library

This folder contains 200 separate original SVG illustration assets for the Rise Again Initiative website. Each file is individually named, accessible, scalable, and uses the initiative's navy, blue, and gold visual identity. These are branded vector illustrations, not documentary photographs; use consented authentic photography for real beneficiary stories.
